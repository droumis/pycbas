How CBAS Works

An interactive walkthrough of the Choice-Wide Behavioral Association Study algorithm.

1 Counting Sequences

Imagine you're watching an animal make choices in a maze. At each decision point it goes Left (L) or Right (R). Over hundreds of trials you get a long stream of choices.

CBAS asks: do certain patterns appear more in one group than another? To answer that, it first needs to count every possible short pattern in each subject's stream.

3

The sliding window moves across the stream and extracts every subsequence of the chosen length. Each unique pattern gets a count. With 2 symbols and length 3, there are 8 possible patterns (LLL, LLR, LRL, ...). With longer sequences or more symbols, the space grows exponentially.

The criterion parameter limits how much of the stream to use. Only windows starting at positions 0 through criterion (inclusive) are counted.

2 Measuring Group Differences

Now you have a count for every sequence for every subject. You split subjects into two groups (e.g. control vs experimental) and ask: for each sequence, do the groups use it at different rates?

The test statistic is a studentized difference: how far apart are the group means, relative to the noise?

t = (mean₀ − mean₁) / √(sem₀² + sem₁²)
t = 3.2

When the groups overlap heavily, t is small. When they're well separated, t is large. CBAS runs two one-sided tests per sequence (group 0 > group 1, and group 1 > group 0) so it can detect differences in either direction.

A sequence only gets a test statistic in the direction that was actually observed. The other direction is set to NaN. This doubles the hypothesis count but handles directionality cleanly.

3 Building the Null Distribution

You have a large t-value for some sequence. But is it large enough? With thousands of sequences, some will have big t-values just by chance. You need to know what "big by chance" looks like.

The bootstrap builds this reference. It shuffles the group labels (pooling all subjects together and redrawing two groups at random), then recomputes the test statistic. Repeat 10,000 times. The distribution of these shuffled statistics tells you what random group splits produce.

0 / 10,000

The histogram shows the null distribution forming. Your observed statistic (red line) sits somewhere in this distribution. If very few null values reach it, that's evidence of a real effect.

All sequences share the same resampled group assignments on each draw. This preserves the correlation structure between sequences, which matters for the step-down procedure next.

4 The Step-Down Procedure

With thousands of sequences tested simultaneously, you need to correct for multiple comparisons. CBAS uses the Romano-Wolf step-down, which is more powerful than simple Bonferroni because it accounts for dependencies between tests.

The idea: start with the largest observed statistic. Compare it against the distribution of the row-maximum across all bootstrap rows. If it's extreme enough, reject it and remove it from the active set. Then look at the next largest, but now compare against the maximum of the remaining (smaller) set. Each step uses a less extreme comparison, so later sequences have an easier threshold to beat.

1

With k=1, you compare against the row maximum (strictest). With k>1, you compare against the k-th largest, which is more lenient. This is where the k-FWER relaxation comes in.

Direction-conditional removal: when a sequence is "removed" from a bootstrap row, it only actually gets removed if the bootstrap went the same direction as the observed stat. This subtlety matches the original Igor implementation and slightly increases conservatism.

5 Finding the Right k

Using k=1 controls the probability of even one false positive (family-wise error rate). That's very strict when you have thousands of tests. The k-FWER procedure relaxes this by tolerating k false positives, where k is chosen to control the false discovery proportion.

The algorithm iterates:

  1. Start with k=1, run the step-down, count how many sequences are rejected (R)
  2. Check: is R small enough that k false positives among R rejections keeps FDP below gamma?
  3. If not, increase k and repeat
  4. When it converges, run the final step-down at the converged k
0.05
The convergence criterion: stop when R < k/γ − 1. At that point, having k false positives among R total rejections gives a false discovery proportion below γ.

6 The Full Picture

CBAS takes a collection of behavioral streams, tests every short pattern for group differences, and returns adjusted p-values (called ζ-values) that account for the massive multiple testing burden. Sequences with ζ < 0.5 are declared significant under median FDP control at the 5% level.

The power of the approach comes from three things working together: the step-down gains power by removing already-rejected sequences, the k-FWER relaxation tolerates a controlled number of false positives, and the shared bootstrap preserves dependencies so the correction isn't overly conservative.
